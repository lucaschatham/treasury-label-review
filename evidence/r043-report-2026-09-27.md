# R-043: inline reference association, failed candidate

September 27, 2026. **FAIL. Stop before application integration.** This is an exposed-development experiment following the supplied Fable handoff, not real-world accuracy qualification.

## Decision

The old vertical gate does discard real inline reference capitals. A bounded geometric chain is not sufficient to repair that safely with the present OCR boxes. The single frozen experimental candidate recovered no usable references on the four primary sources and regressed all three existing real Matches to Review. This violates two preregistered requirements. The candidate stays outside the app; no floor, confidence, cutoff, runtime source or production deployment changed.

This does not reject every possible inline association method. It rejects the recorded candidate and its geometry-only continuation rules with the added conservative ambiguity guards. Do not rerun it with relaxed spacing or confidence limits as a new approach.

## Supported failure explanations

1. **No reliable end-of-statement boundary.** On SIX, the candidate reaches the full observed warning through `problems.` and then examines nearby producer/address and CA CRV regions. Its safety guard rejects the competing continuations, discarding the valid reference chain. On all three existing Matches, the last short warning line (`PROBLEMS.`) sits beside ABV/volume fields. Both spans overlap the prior wide warning row, so geometry alone cannot choose a continuation. This is a mechanism failure, not evidence for relaxing the gap threshold.
2. **OCR word boxes need not be disjoint or faithful.** On Base Camp, According's word box extends from x276 to x489 and overlaps TO, THE and SURGEON. The candidate rejects the overlapping row. On Bruery, ABILITY and TO boxes overlap by 28 px on a later body line. The overlap guard rejects the chain before reference selection. These are saved OCR observations, not speculative model causes.
3. **Numeric confidence does not certify glyph isolation.** Bruery's high-confidence A box includes AC. Simply allowing inline words would pass this box into a stroke estimator designed for individual reference capitals. The chosen candidate abstains before selecting it; no incorrect candidate crop is promoted.

The isolated logic tests used ideal boxes, so their success did not establish real-layout success. The exposed three-Match regression set is enough to reject this candidate without further qualification or latency runs.

## Reopening condition

Keep R-043 failed. A follow-up must demonstrate an actual statement-boundary mechanism, rather than further geometric tolerance tuning. The smallest discriminating next test would use the saved SIX and one existing Match trace: bound the warning with an observed terminal phrase and validate its connection to the heading using observed wording and geometry, then prove nearby producer/ABV text cannot extend or supply the chain. Missing or ambiguous terminal evidence must abstain; never fill OCR gaps with the expected warning. This is a proposed new mechanism, not yet implemented or authorized as a fresh experiment after this stop.

Even a boundary repair would leave malformed heading/glyph boxes and native-resolution limits open. A separate crop-OCR diagnostic might address those, but no second pass, model, confidence change or cutoff change was attempted here. Requirement 3 and blockers D-002/D-004 remain open.
