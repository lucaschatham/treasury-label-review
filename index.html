How to format your CSV or XLSX

Start with a template: Download CSV · Download XLSX. Replace the sample rows with your application details.

  1. Use one row per label image. In filename, enter the exact image filename, including its extension and capitalization, such as old-tom.png. Upload the matching images in Step 1 too.
  2. Keep these lowercase column headings: filename, brand, type, abv, volume, producer, imported, country.
  3. Enter alcohol content as a number, such as 45 for 45% ABV. Include units for net contents, such as 750 mL. Include the producer name and address.
  4. Set imported to true or false. Supply country when imported is true; otherwise it can be blank.
  5. Save CSV as comma-separated text. Put values containing commas in double quotes, such as "Old Tom Distillery, Bardstown, KY". For XLSX, use one populated worksheet with plain values, not formulas.

Required columns: filename, brand, type, abv, volume. Fill each row; leave ABV blank only when an exception applies. One spreadsheet per batch, up to 300 image rows and 1 MB.
