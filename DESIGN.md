# Label Review design system

Direction A, selected by Lucas on 2026-09-22: an Apple-inspired native workspace.

- Use the platform system font, white surfaces, a silver background, and blue actions.
- Keep application details and findings side by side on desktop; stack on narrow screens.
- Group related fields, keep input labels visible, and make the sample easy to find.
- Use status text as well as color. Review and mismatch findings must remain prominent.
- Keep visible keyboard focus, 44px minimum primary controls, 16px text inputs, and reduced-motion support.
- Use local fonts and CSS; no added font downloads or UI dependencies.
- Preserve explicit limitations and separate human confirmation from automated evidence.

The visual update does not establish accuracy, typography, latency, or batch-capacity acceptance. Those remain governed by REQUIREMENTS.md.
